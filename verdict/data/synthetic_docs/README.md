# SYNTHETIC stand-in for HHGOA_IEEE (NOT the official dataset)

Generated by `verdict synth`. Same *shape* as the HHGOA_IEEE dataset so the pipeline can be built
and tested before the real data is available. Replace with the official files for submission.

| File | Contents |
|---|---|
| transactions.csv | IEEE-CIS style columns + `customer_id`, `timestamp`, `channel`, `risk_score`. No fraud label, no card id. |
| identity.csv | Device / connection records for online transactions (`id_*`, `DeviceType`, `DeviceInfo`). `id_15 = New` marks a device new to the account; `id_23` carries proxy flags. |
| closed_cases_history.csv | Closed investigations from months 1-4 (confirmed fraud and cleared). |
| case_pack.csv | 20 benchmark triggers from months 5-6. |
| evidence_responses.csv | What the customer / step-up would return if asked (simulator oracle). |
| fraud_policy.md, fraud_patterns.md, regulatory_references.md | Policy, the five documented patterns, regulatory references. |

Answer format: one JSON file per case `<case_id>.json` (see `verdict/outputs/answer_schema.json`).
